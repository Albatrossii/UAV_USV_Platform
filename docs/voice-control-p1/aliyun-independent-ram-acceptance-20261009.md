# 独立 RAM 凭据的阿里云语音链路验收（2026-10-09）

## 范围

在本机隔离工作树中使用现有智能语音项目的 AppKey，以及独立 RAM 用户的 AccessKey。后端未配置手工临时 Token，由 CreateToken 自动获取和缓存。使用真人预录的四个 WAV 文件验收；录音文件与本机凭据均未加入仓库。

## 结果

| 真人录音原话 | 阿里云转写 | 本地解析与仿真回执 |
| --- | --- | --- |
| 开始任务 | 开始任务。 | START；任务从 PREPARED 进入 RUNNING，算法执行成功，Unity 显示已应用 |
| 暂停任务 | 暂停任务。 | PAUSE；任务进入 PAUSED，算法执行成功 |
| 第一架无人机悬停 | 第一架无人机悬停。 | UAV-001 / UAV_HOVER；算法执行成功，设备进入 HOLDING |
| 第一架无人机返航 | 第一架无人机返航。 | UAV-001 / UAV_RETURN；算法执行成功，设备先进入 RETURNING，随后到达 RETURNED |

四次转写回执的 provider 均为 aliyun-asr。开始、暂停、单设备悬停和返航均通过浏览器的录音文件入口触发，经过阿里云转写、本地意图解析、状态校验和本地仿真执行。暂停后的任务通过页面继续按钮恢复，为单设备命令准备 RUNNING 状态。

## 边界

本次使用真人录音文件，未复测实体麦克风采集。没有“继续任务”“停止任务”的独立真人录音，因此未将这两句列为录音验收通过。没有等待真实 Token 到期，故未现场验证临近过期时自动刷新。上述四句及其对应执行链路已通过；这些未测项目仍需另行验收。
