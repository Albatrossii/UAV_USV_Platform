# E1 Q01/Q02 冻结语料准备说明

Q01、Q02 必须使用同一份人工标注语料，不能把模型输出当作参考文本。语料固定为 60 条、3 位说话人：40 条安静环境、10 条噪声环境、10 条领域术语。每条录音需要人工逐字参考文本、说话人编号、分组、需要命中的术语，以及原文件 SHA256。

录音内容与人员分配已经冻结在 `E1-60条录音任务表.csv`：speaker-a、speaker-b、speaker-c 各 20 条；文件按 `e1-001` 至 `e1-060` 命名。允许扩展名为 wav、webm、ogg、m4a、mp4 或 mp3，每个编号只能存在一个文件。参考文本如需修改，必须先共同更新任务表版本，不能在看到模型输出后回改答案。

私有 manifest 不提交仓库，结构如下：

```json
{
  "datasetId": "e1-zh-60-v1",
  "frozenAt": "2026-09-24T00:00:00Z",
  "normalizationRevision": "nfkc-lower-remove-punctuation-and-separators-v1",
  "samples": [
    {
      "id": "e1-001",
      "path": "D:/private-e1/audio/e1-001.wav",
      "audioSha256": "64位小写SHA256",
      "speakerId": "speaker-a",
      "group": "quiet",
      "reference": "人工核对的逐字文本",
      "terms": []
    }
  ]
}
```

先由任务表和私有录音目录生成带 SHA256 的私有 manifest：

```powershell
& .\asr-service\.venv\Scripts\python.exe .\docs\voice-control-p1\build-e1-corpus-manifest.py `
  --audio-dir D:\private-e1\audio `
  --manifest D:\private-e1\manifest.json
```

冻结后使用 Python ASR 虚拟环境执行：

```powershell
& .\asr-service\.venv\Scripts\python.exe .\docs\voice-control-p1\evaluate-e1-corpus.py `
  --manifest D:\private-e1\manifest.json `
  --model base=C:\Users\hp-pc\Desktop\Project4\Project\UAV_USV_Platform\.local-tools\e1-models\whisper-base `
  --model small=.\asr-service\models\whisper-small `
  --threads 4 `
  --output D:\private-e1\result.json
```

本机已在仓库外准备并离线加载验证 base revision `ebe41f70d5b6dfa9166e2c581c45c9c0cfc57b66`；small revision 为 `536b0662742c02347bc0e980a01041f333bce120`。模型权重、录音和私有 manifest 均不提交仓库。

工具会先强制检查 60 条、3 位说话人、40/10/10 分组、人工参考文本和每个音频哈希；任何一项不满足都会终止。输出包含总 CER、分组 CER、术语命中率、base/small 冷启动、预热 p50/p95、RTF、进程树峰值内存和超时率，不包含音频、参考全文或识别全文。

目前本机只有零散授权录音，没有满足上述规模与人工参考文本的数据集，因此 Q01、Q02 保持 `NOT_RUN`，不能用两条样本或模型自生成文本标记通过。
