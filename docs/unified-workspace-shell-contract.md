# 统一工作台外壳规范 v1

## 目标

系统总览和算法仿真共用同一个视觉外壳。切换工作区时，外壳 DOM、背景、边框、圆角、尺寸和间距不得改变；只有区域内部业务内容与 Unity 画面可以变化。

`frontend/src/styles/workspace-shell.css` 是外壳视觉 token 的唯一来源。业务视图只能使用这些 token，不得重新声明同名变量。

## 固定区域

| 区域 | 固定内容 | 允许变化的内容 |
| --- | --- | --- |
| 页面框架 | 背景、总高度、左右列、区域间距 | 无 |
| 左侧控制台 | 外框、标题栏、背景、边框、折叠宽度 | 语音、任务配置、平台节点内容 |
| 顶部任务栏 | 外框、背景、高度、边框、内边距 | 算法名称、任务按钮、视角按钮 |
| Unity 区域 | 视口外框、圆角、裁切方式 | 当前 Unity 实例及其画面 |
| 底部面板 | 外框、背景、高度、边框 | 设备控制或节点视角内容 |

## 桌面基准

| 项目 | 规范 |
| --- | --- |
| 左栏宽度 | `clamp(238px, calc(20vw - 48px), 317px)` |
| 页面高度 | `calc(100dvh - 102px)`，最小 `560px` |
| 顶部任务栏高度 | `54px` |
| 底部面板高度 | `130px` |
| 左右列间距 | `10px` |
| 主区域上下间距 | `8px` |
| 页面背景 | `#061113` |
| 面板背景 | `rgba(8, 25, 30, .94)` |
| 控制台背景 | `#0b2025` |
| 顶部任务栏背景 | `linear-gradient(100deg, #112b32, #091e27)` |
| 底部面板背景 | `#0a2028` |
| 基础边框 | `rgba(108, 228, 213, .18)` |
| 强边框 | `#31525b` |
| 面板圆角 | `8px` |

在工作区宽度不超过 `1100px` 时，顶部任务栏和底部面板分别使用 `94px` 与 `206px`；不超过 `760px` 时进入纵向流式布局。

## 后续组件约束

1. 共享外壳必须只有一个实例，并带有 `data-workspace-shell-contract="v1"`。
2. 工作区切换不得卸载 Unity 实例或重建共享外壳。
3. 业务内容组件不得设置外壳的背景、边框、圆角、宽高和区域间距。
4. 左栏折叠状态由共享外壳持有，不能分别保存在两个业务页面中。
5. 所有外壳调整必须先更新本规范与 `workspace-shell.css`。

## 当前组件层级

`UnifiedWorkspaceShell.vue` 现在持有唯一可见的 `TaskConsoleShell`、
`WorkspaceToolbarShell`、`WorkspaceViewportShell` 和
`WorkspaceBottomPanelShell`。`DashboardView` 与 `VirtualFleetConfigView` 只把
各自的控制台、工具栏、Unity 画面和底部业务内容传送到共享目标；切换工作区
不会替换任何共享外框，也不会重置共享左栏的折叠状态。

底部业务内容必须以共享面板的实际宽高为容器进行布局。设备卡片在低高度时
只保留设备编号、状态和核心身份信息，在窄宽度时切换为三列或两列；任何子项
都不得依靠固定最小高度突破共享面板边界。

## 最终视觉验收

在相同视口下分别切换系统总览和算法仿真，逐项比较页面框架、左侧控制台、顶部任务栏、Unity 外框和底部面板：

- `x`、`y`、`width`、`height` 差值必须为 `0px`；
- `background`、`border`、`border-radius`、`box-shadow`、`padding` 和 `gap` 的计算样式必须完全相同；
- 切换过程中共享外壳 DOM 实例不得变化。
