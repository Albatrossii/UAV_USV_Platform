# 系统总览语音控制接入约束

系统总览与算法仿真共用 `VoiceP0ControlPanel`、语义解析、提案、确认、幂等和审计模型，但不共用执行通道。

## 执行路径

1. 总览页面每 3 秒调用 `POST /api/voice/contexts/system-overview/sync`。
2. 后端从任务服务重新读取任务状态和绑定设备，创建 `SYSTEM_OVERVIEW / REAL_MISSION / ROS_GATEWAY` 上下文；浏览器只上报运行实例标识，系统总览不依赖 Unity 场景生成。
3. 语音或文本只生成冻结提案。系统总览命令不会自动确认，必须由管理员显式确认。
4. 确认后的任务级命令复用 `MissionService`，单设备命令复用 `RuntimeControlService`，执行结果从已有运行时命令记录回写。
5. Unity 展示绑定只属于算法仿真。系统总览的执行回执来自任务/ROS 控制链，不把 Unity 画面变化当作物理指令成功。

## 安全边界

- 只允许 ADMIN 同步、创建和确认提案。
- 任务状态、算法和设备成员以服务端任务快照为准。
- 心跳超过 5 秒、任务状态变化、设备集合变化或运行实例变化都会阻止执行；影响冻结计划的变化会递增 `contextVersion`。
- 录音、识别以及 START/RESUME 均不要求生成 Unity 场景；确认和派发时仍会重新校验任务状态、成员快照、心跳和管理员权限。
- 单设备指令必须属于当前任务成员，且 UAV/USV 指令类型必须匹配。
- 执行使用原确认操作员身份，并再次检查账号仍启用且仍为 ADMIN。
- 外部结果不确定时标记 `TIMED_OUT / UNKNOWN`，不自动重发物理动作。

## 当前人工验收项

- 使用实际 ROS 网关验证每种任务级和单设备指令的 ACK 状态映射。
- 验证浏览器麦克风权限、现场噪声下的识别质量和中文设备编号解析。
- 断开 Unity 后确认仍可录音和识别；断开 ROS 或任务心跳后确认旧提案不可继续执行。
- 逐条核对任务事件、运行时命令和语音审计记录能通过同一执行标识追踪。
